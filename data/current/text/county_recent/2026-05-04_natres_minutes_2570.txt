7. Agenda Items
a. An Ordinance Amending the Community Development Code (CDC): Table 3.1.60 (Consolidated
Use Table), Table 3.2.40. H (T2R Allowed Uses), and Division 4.1 (Specific to Use) (FISCAL
IMPACT: ) - Robert Merchant, AICP, Beaufort County Planning and Zoning Department
Motion: It was moved by Committee Member Passiment, seconded by Committee Member Tabernik to
approve an Ordinance Amending the Community Development Code (CDC): Table 3.1.60 (Consolidated
Use Table), Table 3.2.40.H (T2R Allowed Uses), and Division 4.1 (Specific to Use).
Motion: It was moved by Council Member Passiment, seconded by Council Member Dawson to
approve an Ordinance Amending the Community Development Code (CDC): Table 3.1.60 (Consolidated
Use Table), Table 3.2.40.H (T2R Allowed Uses), and Division 4.1 (Specific to Use) for the following
reasons: it is consistent with the goals, objectives, and policies of the Comprehensive Plan; it is not in
conflict with any provisions of this Development Code or the Code of Ordinances; it is required by
changed conditions; it does address a demonstrated community need; it is consistent with the purpose
and intent of the zones in this Development Code, or would improve compatibility among uses and
ensure efficient development within the County; it would result in a logical and orderly development
pattern; and it would not result in adverse impacts on the natural environment including but not limited to
water, air, noise, stormwater management, wildlife, vegetation, wetlands, and the natural functioning of
the environment.
The Vote - Voting Yea: Committee Chair Glover, Committee Vice-Chair McElynn, Committee Member
Dawson, Committee Member Tabernik, Committee Member Passiment, and Council Member Brown.
The motion passed 6:0.
